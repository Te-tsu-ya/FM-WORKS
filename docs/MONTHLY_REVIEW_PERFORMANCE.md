# 月次勤怠確認：社員別検索によるI/O削減（2026-10-10）

- 目的：月次確認を保存するとき、スプレッドシート全社員×全月の10列を毎回読み込まない。
- 仕様：社員ID列2で完全一致検索し、該当社員の行の月列1だけを照合する。既存行なら10列を1行だけ取得して上書きする。新規なら既存行数の末尾に1行追記する。
- 既存の認証、月次サマリーの未確認打刻・工数差異チェック、監査記録、作成日時の保持は変更しない。
- 影響範囲：src/Monthly.gs の confirmMonthlyReview のシート参照のみ。総務・経理・社員/有給台帳の処理は変更しない。
- テスト：scripts/test_monthly_review_index.mjs で複数社員・複数月の混在、既存月更新、他社員行の保持、新しい確認行の登録、ブロッカー、全件10列読取の禁止を検証。
- 効果：Sheet APIの転送データ量と一覧走査を削減する。実GASでの秒数短縮は認証付き計測が必要。
