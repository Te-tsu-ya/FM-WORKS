## 今回の修正
1. 既存「申請」シートの宣言ヘッダーを実DBと一致。DB更新前の全対象ヘッダー事前検査を追加し、不一致時は変更前に停止。
2. 長期間の日付検索で、インデックス非対応時に範囲外行を返してしまう問題を修正。
3. 経費・出張の差戻し後に本人が修正・再申請できる処理を追加。本人以外／承認待ちへの書き換えは拒否。
4. 経理の承認前に証憑・用途・出張結果・宿泊等の詳細を表示。
5. 経費申請と経費記録を同じ証憑整理番号で照合し、複数申請・差額・未登録を区別。
6. 承認待ち・精算待ち・差戻しを優先表示。最大1000件の追加表示、原本DBは削除しない。
7. 架空のメモリ内シートを使った統合テスト、ロジックテスト、画面契約テストを拡充。
